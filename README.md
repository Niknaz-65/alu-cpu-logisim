# 8-bit ALU & Simple CPU (Logisim)

This project implements an 8-bit Arithmetic Logic Unit (ALU) and a simple CPU using Logisim-evolution.  
It was created for UMGC CMSC 306: Computer Architecture.

## 🔧 Features
- 8-bit ALU supporting ADD, INC, DEC, CMP, NOT, AND, OR, SHR, SHL, and extended operations  
- Three 8-bit registers (REG_A, REG_B, REG_OUT)  
- Control unit for loading and executing instructions  
- Shared datapath and status flags  
- Test program to verify instruction flow and operations  

## 📄 Project Files
- **CPU_Project.pdf** – Full technical report explaining the design, architecture, and test results  
- **ALU.circ** – Logisim circuit file for the ALU and simple CPU

## 🧠 Technologies
- Logisim-evolution  
- Digital logic design  
- CPU architecture concepts
